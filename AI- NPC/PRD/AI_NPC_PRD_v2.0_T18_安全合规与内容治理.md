# T18 安全、合规与内容治理 需求表

> 所属文档集：AI NPC 可交互世界 · 产品需求文档 v2.0（总表 + 小表）
> 状态标记：**明确**＝用户已确认；**基线**＝原产品手册已有；**建议**＝我方提案待确认；**首版建议／已确认+细节建议**＝v1.1 增补状态；**待定**＝未决，见 T19 未解决问题清单。
> 本表只写需求与验收口径，不规定任何视觉风格、配色、字体与动效；界面承载清单见 T20。

## 一、需求明细

| 编号 | 状态 | 需求 | 优先级 |
| --- | --- | --- | --- |
| SAF-01 | 社区上传、公开展示、混搭再发布都有内容政策检查；提供举报、人工复核、下架与必要申诉流程 |  | — |
| SAF-02 | 角色包和用户提示词不能绕过安全策略；对输入、结构化动作、输出、展示和外部调用分别设边界，不声称提示词能绝对防注入 |  | — |
| SAF-03 | 禁止未成年人性化/剥削内容；恋爱路径设置适龄、意愿与内容分级，年龄不明不进入成人内容路径 |  | — |
| SAF-04 | 不将礼物、高好感、付费或连续登录当作强制亲密权限；允许拒绝、冷却、结束关系和关闭相关内容 |  | — |
| SAF-05 | 玩家画像默认私密，说明用途和发送范围；提供查看、纠正、删除和停止采样，不伪装心理诊断 |  | — |
| SAF-06 | 私人聊天、礼物关系史、NPC 私密记忆和真人画像不默认上传广场；分享有明确范围预览与确认 |  | — |
| SAF-07 | 世界/角色/图像等素材核验使用与再创作许可，保留出处，处理侵权申诉；手册中的预制内容不代表获得公开发行授权 |  | — |
| SAF-08 | 内容包作为数据而非程序导入；校验外部资源、字段和大小，不执行包内脚本/命令，不让其读取 API Key |  | — |
| SAF-09 | 清楚提示 NPC 和动态是 AI/模拟世界内容；不冒充真人，不用内疚、威胁、失联惩罚等方式强迫用户持续互动 |  | — |
