# AI NPC 可交互世界

> 一款以对话为入口，让 NPC 拥有持续记忆、自主生活和真实关系的沉浸式互动软件。

---

## 软件简介

玩家可以进入不同世界，与拥有独立人格、记忆、日程和关系的 NPC 进行**私聊、群聊和酒馆互动**，也可以送礼、建立关系并推动剧情。

同一个 NPC 在同一世界中只有一个身份和一套状态。切换聊天窗口不会生成新的角色副本，NPC 的经历会持续影响后续的**记忆、行为、日程和关系**。

软件还提供世界和角色创作功能。用户可以创建世界观、人物和规则，将作品发布到社区；也可以下载其他用户的完整世界或单个角色，经过冲突检查后组合成新的世界。

## 核心特点

- **对话优先：** 支持私聊、群聊和酒馆互动。
- **持续记忆：** 重要经历会被 NPC 记住，并影响后续交流。
- **自主生活：** NPC 拥有自己的目标、日程和行为选择。
- **真实关系：** 好感、信任、熟悉度和关系变化相互独立。
- **认知一致：** NPC 只能使用自己能够感知、获知并记住的信息。
- **互动有后果：** 送礼、承诺和选择会持续影响世界状态。
- **自由创作：** 支持创建、导入、导出和分享世界、角色与规则。
- **多模型支持：** 用户可以自行配置不同的 AI 模型服务。

## 软件架构

软件采用 **本地核心 + 模块化云服务** 的分阶段架构。

### 1. 客户端

客户端负责：

- 对话、群聊和酒馆交互
- 世界与 NPC 的创建和编辑
- 关系、生活动态和事件记录
- 模型与 API 配置
- 本地存档及内容导入导出
- 感知范围和可见信息呈现

第一阶段可以仅依靠客户端完成核心体验，避免账号和社区服务阻塞基础功能。

### 2. 世界运行核心

世界运行核心由四个中枢组成：

- **记忆中枢：** 管理每个 NPC 的短期记忆、长期记忆、遗忘和按需召回。
- **决策中枢：** 根据性格、目标、关系、风险和环境选择 NPC 的行为。
- **日程中枢：** 管理位置、活动、预约和时间冲突，确保角色不会分身。
- **关系中枢：** 管理好感、信任、熟悉度、情绪和关系变化。

所有互动先由系统校验并完成状态结算，再由 AI 生成与结果一致的文本。**AI 模型不能直接修改世界状态**，从而避免重复送礼、关系重复结算或文本与事实不一致。

### 3. 知识与感知系统

信息按照以下顺序处理：

1. 世界中实际发生的事件
2. 角色是否能够感知
3. 角色是否实际获知
4. 角色是否相信
5. 角色是否能够从记忆中召回

只有经过过滤的信息才会提供给 AI 模型，避免 NPC 知道自己不应该知道的秘密，并保证距离、视线、遮挡和听觉规则保持一致。

### 4. AI 模型层

模型层支持**用户自备 API、多种模型服务商和本地模型**，主要负责：

- 生成对话和叙事
- 辅助表达 NPC 的行为决策
- 创建世界和人物
- 总结记忆与事件
- 融合不同来源的世界设定

模型调用受到上下文、调用次数和 Token 预算控制。没有可用模型时，用户仍然可以编辑世界、管理人物和查看记录。

### 5. 数据层

- **世界定义：** 可共享的世界观、规则和人物模板。
- **运行存档：** 玩家游玩过程中产生的事件、记忆、日程和关系。
- **账号资产：** 用户资料、收藏、表情和已发布作品。
- **私密数据：** 聊天记录、玩家画像、角色秘密和 API 密钥。
- **公开作品：** 经过用户确认后发布的世界包或角色包。

不同世界、NPC、会话和生成任务使用独立标识进行隔离。公开作品默认不包含私人聊天、玩家画像、私密记忆和模型密钥。

### 6. 云端服务

云端能力按开发阶段逐步加入：

- 账号登录与设备管理
- 云存档及后续多端同步
- 社区作品存储、发布和审核
- 离线世界调度与模型预算
- 举报、内容治理和运营后台
- 去标识化的产品分析

模块化云后台只负责对应服务，**不代表所有玩家共享同一个运行世界**。

## 建设阶段

1. **本地可玩闭环：** 完成对话、世界、NPC、记忆、决策、日程和关系系统。
2. **账号与存档：** 加入登录、自动保存、存档恢复和统一错误提示。
3. **社区与离线运行：** 加入作品发布、下载、世界混搭和离线推进。
4. **运营与优化：** 加入内容审核、运行监控和数据分析。
