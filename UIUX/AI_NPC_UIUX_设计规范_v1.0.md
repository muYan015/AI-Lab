## 一、设计原则

五条原则，按优先级排序。冲突时按序号靠前的为准。

| # | 原则 | 一句话 | 它约束的具体决策 |
| --- | --- | --- | --- |
| P1 | **不撒谎** | 界面呈现的信息，必须和世界里真实发生的事一致 | 不可辨内容只给线索；系统故障绝不伪装成角色不理人；未保存不显示「已保存」 |
| P2 | **状态可辨** | 每一种"还在路上"的事，都要有独立、可区分的样子 | 意图／执行中／已确认／被拒绝／失败五态分离；忙碌／缺席／生成中／等待各有其形 |
| P3 | **边界可见** | 谁能知道什么，界面上要能被感知到 | 感知范围用虚线表达；受众外内容不出现；分享前给范围确认 |
| P4 | **内容优先** | 视觉退到文字后面，不做装饰性抢戏 | 单色系 + 一个强调色；无渐变炫技；动效只服务于状态变化 |
| P5 | **同一套说法** | 同一动作在所有界面同一名称、同一结果 | 「删除」不在这里叫删除、那里叫移除；拒绝与失败不混用颜色 |

**反面清单（做设计评审时逐条查）**：给关系加数值条、用红色表达「角色拒绝」、把系统报错写成角色台词、用加载动画掩盖「其实没在动」、把感知范围外的信息用灰色"预告"出来、为了填满版面生成占位剧情。

## 二、设计语言定位

**「纸与墨 · 一间有人味的屋子」**

产品是「坐在酒馆里看他们过日子」，不是后台管理系统，也不是赛博聊天机器人。因此：

- **界面 90% 无彩**：暖纸白 `#FBFAF8` 打底，墨黑 `#17191B` 承载文字、控件、选中态与"我的"气泡；
- **唯一的彩色 = 行动色** `#316C87`（石青），只用于主行动按钮与关键链接，用量控制在 5% 以内——正因如此，主按钮一出现就天然是视线焦点。**醒目靠对比度，不靠到处撒彩色**；**舒服靠低饱和**：石青饱和仅 47%，是矿物颜料感而非屏幕蓝的电子感；
- 语义色（成功 / 警告 / 危险 / 中性灰）是功能性用色，不受"90% 无彩"限制，但也只出现在状态上；
- 不使用霓虹、玻璃拟态、彩色渐变、大面积品牌色；
- 圆角中等（12px 为主），描边极淡（1px `rgba(23,25,27,.06)`）；**导航与分区不用硬边框**，靠底色微差和留白分隔，减少割裂感——侧栏与画布同色，选中项用白卡 + 柔和阴影表达；
- 投影柔和：暖灰低透明 + 大扩散，不用生硬的黑投影（见 3.4）；
- 世界设定、纪事、人物背景这类"文本作品"，允许用衬线体做标题，制造"这是一本书"的轻微暗示；交互控件一律无衬线。

**品牌与语义**

| Token | 值 | 用途 | 对比度（对白底） |
| --- | --- | --- | --- |
| `--ink` | `#17191B` | **主色（墨黑）**：选中态、左竖条、"我的"气泡、聚焦环 | 15.8:1 ✅ |
| `--ink-soft` | `#F1EFEA` | 墨的极淡底：悬停、选中底色 | — |
| `--action` | `#316C87` | **唯一彩色行动色（石青）**：主按钮、关键链接、"处理中/生成中" | 5.8:1 ✅ |
| `--action-hover` | `#275A72` | 行动色悬停态 | 7.5:1 ✅ |
| `--action-press` | `#1E495C` | 行动色按下态 | 9.7:1 ✅ |
| `--action-ink` | `#21566E` | 行动色文字版：链接、chip 文字 | 7.7:1 ✅ |
| `--action-soft` | `#EEF3F7` | 行动色淡底：选中行、进行中提示块 | — |
| `--grad-soft` | `#FFF → #FBF9F6` | 卡片信息区的极淡渐变过渡（单色系，非彩色渐变） | — |
| `--success` | `#3D7355` | 已确认、已保存、已完成 | 5.6:1 ✅ |
| `--warning` | `#8A6A1F` | 降级、额度将尽、待校准 | 5.0:1 ✅ |
| `--danger` | `#A83B32` | **仅**系统/事务失败、危险操作 | 6.3:1 ✅ |
| `--neutral-state` | `#667075` | **角色侧拒绝、缺席、取消**——不用红色 | 4.9:1 ✅ |

> **行动色为什么是石青 `#316C87`**：色相 199° 往青偏，是矿物颜料"石青"的方向而非屏幕蓝；饱和 47%，比浏览器默认蓝低一半——**低饱和是"舒服"的来源，高对比是"醒目"的来源，两者不冲突**。与三个语义色的色相间距均 ≥56°，不会混淆。备选值：陶土赤陶 `#B03A1E`（更暖更有灯火感，但与危险红仅差 7°，须连带把 `--danger` 改为冷绯红 `#A11D2C`）；酒渍紫 `#6E3A54`（低饱和高对比 8.8:1，但紫易带 AI 产品味）。

> ⚠️ **颜色语义铁律**：`--danger`（红）= 系统或事务失败；`--neutral-state`（灰）= 角色意愿造成的拒绝、缺席、结束关系。二者绝不能互换。这是 RK-10 在视觉层的落点。

**认知语义色（本产品特有）**

| 语义 | 视觉表达 | 说明 |
| --- | --- | --- |
| 清晰可辨 | 实线气泡，正常字重，`--bg-surface` | 你确实听到/看到了 |
| 部分可辨 | 虚线 1px 边 + 斜体占位文本 + 「听不清」角标 | 有声音但不是原文，绝不补全 |
| 转述/声称 | 引号包裹 + 「据 X 说」来源行 | 声称不是事实 |
| 不在受众内 | 完全不渲染（不是灰掉，是根本不出现） | 灰掉也算泄漏 |
| 感知范围 | 俯视小窗内虚线圆 + `--brand` 20% 填充 | 圈外一律不画 |

- 行内代码、ID、错误码用 mono；
- 禁止纯大写英文长句；标签类（≤8 字符）可用大写 + 0.06em 字距。

### 3.3 间距与栅格

基准 **4px**。

| Token | 值 | Token | 值 |
| --- | --- | --- | --- |
| `--sp-1` | 4px | `--sp-6` | 24px |
| `--sp-2` | 8px | `--sp-8` | 32px |
| `--sp-3` | 12px | `--sp-10` | 40px |
| `--sp-4` | 16px | `--sp-12` | 48px |
| `--sp-5` | 20px | `--sp-16` | 64px |

- 卡片内边距：**20px**（移动 16px）；卡片间距：**16px**；
- 表单字段垂直间距：**20px**；标签与控件间距：**8px**；
- 分区之间：**40px**（移动 32px）；
- 同级元素之间只用 4 的倍数，禁止出现 10/15/18 这类值；
- **间距即语义（就近原则）**：关联性强的内容必须挨得更近——物品名与数量之间 6px、字段与说明之间 6–8px、同组内容 16px、不同组 24–40px。用户靠间距读出结构，而不是靠分隔线。

**信息层级（突出核心信息）**

- 每个卡片 / 弹层 / 列表项**只允许一个视觉焦点**：重点对象用 +2px 字号、600 字重，其余信息一律 14px 以下、400 字重；
- 次要信息（来源、时间戳、编号）用 `--text-muted`，不许与核心信息同级同重；
- 禁止用加粗"刷存在感"——一屏内加粗超过 5 处即视为层级失效。

**栅格**

| 断点 | 名称 | 列数 / 槽宽 | 页面左右留白 | 内容最大宽 |
| --- | --- | --- | --- | --- |
| ≥1600 | 宽屏 | 12 / 24 | 40 | 1440 |
| 1280–1599 | 桌面 L | 12 / 20 | 32 | 1280 |
| 1024–1279 | 桌面 | 12 / 20 | 24 | 1024 |
| 768–1023 | 平板 | 8 / 16 | 24 | — |
| 360–767 | 手机 | 4 / 12 | 16 | — |
| <360 | 小屏 | 4 / 12 | 12 | — |

**内容宽度上限（阅读舒适度优先）**

| 内容类型 | 最大宽 |
| --- | --- |
| 对话消息流 | 720px |
| 长文阅读（纪事、设定、简报） | 680px |
| 表单（单列） | 640px |
| 列表 / 网格 / 看板 | 跟随容器，不设上限 |

### 3.4 圆角、描边、阴影

| Token | 值 | 用于 |
| --- | --- | --- |
| `--r-xs` | 4px | 角标、徽章、进度条 |
| `--r-sm` | 8px | 输入框、按钮、Chip、菜单项 |
| `--r-md` | 12px | **卡片、面板、会话气泡**（默认） |
| `--r-lg` | 16px | 弹层、抽屉 |
| `--r-xl` | 24px | 空状态插画容器、引导页卡 |
| `--r-pill` | 999px | 状态点、计数徽章、分段控件的胶囊 |

- 描边统一 1px 极淡墨 `rgba(23,25,27,.06)`；聚焦时 1px `--ink` + 3px `rgba(23,25,27,.10)` 外环；
- 气泡的"指向角"仅在私聊首条出现，半径 4px，不做拟人化大尾巴；
- **阴影必须柔和**：暖灰 `rgba(28,25,22,…)` + 低透明度 + 大扩散，**不用生硬的黑投影**。层级靠底色深浅与阴影共同建立，不靠投影堆叠：

```css
--sh-sm: 0 1px 2px rgba(28,25,22,.035), 0 6px 16px -8px rgba(28,25,22,.055);   /* 卡片静止 */
--sh-md: 0 2px 4px rgba(28,25,22,.04), 0 16px 32px -12px rgba(28,25,22,.085);  /* 悬停/下拉 */
--sh-lg: 0 4px 10px rgba(28,25,22,.05), 0 36px 64px -20px rgba(28,25,22,.13);  /* 弹层/抽屉 */
```

- 悬停反馈只**加深阴影**，不做位移、不做缩放；
- **卡片信息区用同色系渐变过渡**：`--grad-soft`（`#FFFFFF → #FBF9F6`，差 2%），让层次柔和、不突兀。**禁止彩色渐变**——渐变只允许存在于这一个变量里。

**头像与背景衔接**

- 头像不用纯灰平涂：底色为 `linear-gradient(160deg,#F9F7F3,#EDE9E2)`，与纸感呼应，外缘加 1px `rgba(23,25,27,.07)` 内描边——头像"嵌"在界面里，而不是浮在表面；
- 状态点始终带 2px 白描边，与头像底融合。

### 3.5 图标

- 风格：**线性 1.5px，圆头圆角，24×24 网格，视觉重心居中**；同一语义全应用只有一枚图标；
- 实心仅用于：选中态的导航图标、状态点、警示类（错误/危险）；
- 每个图标按钮必须有 `aria-label`；纯装饰图标 `aria-hidden`；
- 禁止用图标单独表达关键状态——图标必须配文字或角标（色盲与读屏可用）。

### 3.6 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 颜色/透明度变化（悬停、按下） | 120ms | `ease-out` |
| 小位移、展开收起、Toast | 200ms | `cubic-bezier(.2,.8,.24,1)` |
| 弹层/抽屉进出 | 240ms 进 / 160ms 出 | 同上 |
| **滚动触发淡入**（规范预览页、引导页、空状态） | 450ms，位移 14px | `cubic-bezier(.2,.8,.24,1)` |
| 骨架屏/加载 | 1.2s 循环 | `ease-in-out` |

- **滚动触发**（IntersectionObserver）：元素进入视口时淡入上移，**只触发一次**，不反向播放；同一屏最多 2–3 个元素同时入场，不做逐字逐卡的连续舞台动画；必须带兜底——1.5s 内未触发的元素强制显示，防止锚点直跳、打印、爬虫场景下内容不可见。

规则：
- 位移 ≤ 8px，缩放 ≤ 1.02，**禁止弹跳、回弹过冲、无限循环**（骨架屏除外）；
- 生成中的"流式文字"只做逐字出现，光标用 1px 竖线，不闪烁；
- `@media (prefers-reduced-motion: reduce)`：全部降级为 80ms 淡入或直接切换，移除位移与循环动画；
- 动效只用于表达"状态变了"，不用于吸引注意。

### 3.7 图像与蒙版

- 本产品当前**不使用照片或插画背景**，界面全部为纯色、线稿与文字；
- 一旦在图像上叠字：图像底部加 `linear-gradient(180deg, rgba(23,25,27,0) 30%, rgba(23,25,27,.62) 100%)` 蒙层，文字纯白，并重新核算对比度（≥4.5:1）；
- **禁止**把正文、状态文字放在无蒙版的图像上；
- 酒馆俯视小窗的地图标签用半透明白底（`rgba(255,255,255,.8)`）而非黑蒙层——地图是"观察对象"，不是"海报"。

## 四、信息架构与导航

### 4.1 三个一级入口（已确认，待树测试验证 UNR-H01）

```
对话  ◀── 默认落地页，第一入口
 ├─ 会话列表（私聊 / 群聊 / 酒馆）
 ├─ 动态聚合流（世界的today）
 └─ 名册（人物入口，也可从消息内进入）
世界
 ├─ 我的世界（模板 / 运行存档 / 副本）
 ├─ 世界详情（七类设定、人物、关系）
 ├─ 创作与编辑（世界 / NPC / 规则）
 └─ 社区广场（浏览、下载、混搭、发布管理）
我的
 ├─ 资料卡、偏好总结
 ├─ 本人作品（草稿 / 审核 / 版本 / 下架）
 ├─ 收藏、表情、私人笔记
 └─ 设置（模型 API、数据隐私、通知、无障碍）
```

- 落地页**必须是会话列表**，不能是「世界」或引导（P0，总表验收样例之一）；
- 「我的作品」主入口放**我的**，不放广场（UIX-46）；
- 高频直达（UIX-10）：最近会话 ×3、当前世界、继续上次创作。桌面常显于侧栏顶部；手机收进顶部悬浮按钮，长按展开。

### 4.2 导航形态

| 端 | 形态 | 规格 |
| --- | --- | --- |
| 桌面 ≥1024 | 左侧固定栏 | 宽 240px，顶部直达区 + 三入口 + 底部当前世界切换器与设置入口；当前项用 `--brand-soft` 底 + 左侧 3px `--brand` 竖条 |
| 平板 768–1023 | 左侧栏收窄为图标栏 64px，点击展开为浮层 | 三入口 + 直达 |
| 手机 | 底部标签栏 | 高 56px + 安全区；3 项；图标 24 + 12px 标签；选中项图标实心 + `--brand`；中间不放凸起按钮 |

- **当前世界切换器**（UIX-11）常驻框架顶部，格式：`世界名 · 你的身份 · 世界内时间`。切换后必须同时更新：会话列表、名册、关系、纪事、身份档案——任何一处未同步即为缺陷；
- **导航减少割裂感**：侧栏与画布同色、无硬边框，选中项用白卡 + `--sh-sm` 表达；分区之间用留白与底色微差，不用通栏分割线；

**便当盒（Bento）布局的适用边界**

| 场景 | 是否可用 | 说明 |
| --- | --- | --- |
| 规范/概览页、引导页、我的主页资产分区、设置分组 | ✅ 推荐 | 大小不一的圆角卡（20px），信息密度低、彼此独立时效果好 |
| 界面功能稿（会话、酒馆、表格、时间线） | ❌ 禁止 | 功能界面必须保持真实比例与任务流，不做装饰性格子 |
- **返回定位不丢**：从会话 → NPC 名片 → 返回，回到会话且滚动位置不变。列表类页面进入详情再返回，保留筛选与滚动。

### 6.4 通用状态要求（UIX-G01 落地）

| 状态 | 要求 |
| --- | --- |
| 空 | Empty 组件：说明"为什么是空的" + 一个能开始的行动 |
| 加载中 | 首次 → 骨架屏；刷新 → 顶部 2px 进度条 + 内容保持；>3s → 显示「仍在加载，可继续等待」 |

| 边界 | 长名称截断为单行 + tooltip；超长段落保留滚动不撑破；列表 >200 项虚拟滚动；≤360px 窄屏不出现横向滚动 |

## 七、六套语义系统（本产品的核心差异）

> 这六套系统是本规范最重要的部分。它们是 PRD 里"可验收的真实感"在界面上的唯一落点。

### 7.1 S1 · 认知与可见性

| 情况 | 界面表达 | 禁止 |
| --- | --- | --- |
| 你听清了 | 正常气泡，实线 | — |
| 有声音但听不清 | 虚线气泡 + 斜体占位：`……（隔了三张桌子，只听见有人在笑）` + 「听不清」角标 | 不得给出关键词、不得"猜一个大概" |
| 看见了动作 | 动作行（系统叙述体，13px `--text-muted`，居中） | 不得替角色补台词 |
| 转述 | 引号 + 来源行「据 老陈 说」+ 「转述」角标 | 不得把转述渲染成事实陈述 |
| 你不在受众内 | 完全不渲染 | 不得灰显、不得"有 1 条你看不到的动态" |
| 俯视小窗 | 只画可感知范围内的人与移动；圈外用纯底不画 | 不得用暗色暗示"那里有人" |

### 7.2 S2 · 事务三段式（送礼 / 邀请 / 承诺 / 移动）

状态机：`意图 → 待确认 → 执行中 → 已确认 / 被拒绝 / 失败`

| 状态 | Chip 文案 | 颜色 | 界面行为 |
| --- | --- | --- | --- |
| 意图已表达 | 待确认 | `--neutral-state` 虚线 | 显示确认卡：送什么、给谁、可取消。**不扣减、不结算** |
| 执行中 | 处理中 | `--brand` | 禁用重复提交；显示进度；关闭页面不中断（可回到此处看结果） |
| 已确认 | 已确认 | `--success` | 写入流水与纪事；可被后续引用 |
| 被拒绝 | 被拒绝 | `--neutral-state`（**不是红**） | 说明是谁拒绝、为什么（角色侧）；可换个方式再来 |
| 失败 | 未完成 | `--danger` | 走系统错误家族；明确"没有送出、没有扣减"；重试只重试表达 |

规则：
- 幂等在界面可见：同一 `eventId` 的重试，UI 显示"你已在 3 分钟前送出，正在确认结果"，**不出现第二个赠送入口**；
- 结果未回来前，角色**不得**显示"收下了"（UNR-C01）。生成中的角色发言与确认结果分离渲染。

### 7.3 S3 · 角色状态 vs 系统状态（RK-10 视觉落点）

| 类别 | 例子 | 视觉 | 文案主语 | 后续 |
| --- | --- | --- | --- | --- |
| **角色侧** | 忙碌、缺席、不想说、拒绝、结束关系 | 中性灰；气泡内叙述体，带角色头像 | 「老陈这会儿在忙，没搭话」 | **必须给可替代下一步**（找别人 / 稍后再来 / 留言） |
| **系统侧** | 请求失败、配额耗尽、存储失败、网络断开 | 统一弹窗，`--danger`；右上错误码 + 复制按钮 | 「请求失败（ERR-MODEL-429）」 | 重试 / 查看状态 / 联系支持 |

铁律：**任何系统故障不得写成角色台词**。反之，角色拒绝不得弹出系统弹窗。二者在颜色、位置、文案主语上三重区分。

统一错误弹窗结构（UIX-06）：
```
[图标] 标题：发生了什么（不含角色名）
       说明：影响范围（本局 / 账号 / 全局）+ 已发生什么
       错误码：ERR-XXX-000            [复制]
       主行动：重试 ｜ 次行动：查看状态页
```

### 7.4 S4 · 关系与好感呈现（不显示数值，UNR-C04 待校准）

- 关系用**描述 + 方向**表达，不用分数、进度条、星级、百分比；
- 双向不对称：用两个方向的行分别描述（A 对 B：_敬重但不亲近_；B 对 A：_视为对手_），不合并成一个"关系值"；
- 拆分维度各自成行：对人的关系 / 对行为的喜好 / 短期情绪 / 稳定关系类型，不加权求和；
- 关系变化（UIX-30）必须给：方向（↑↓）、触发事件（可点回原会话）、观察者是谁、原因一句话。**无证据时不显示任何数值或曲线**；
- 亲密与恋爱边界（UIX-31）：条件不满足时给出「还不到这一步」+ 缺哪个条件，**不给"再送 3 次礼物就能解锁"这类引导**。

### 7.5 S5 · 编辑影响与历史

- 编辑已运行的世界前，先给**影响预览弹层**（UIX-64）：将影响 N 段叙事 / N 条记忆 / N 组关系；
- 明确告知：**已执行的流水不退**（UIX-15），可部分应用；
- 编辑中的字段左侧显示 2px `--warning` 竖条 + 「将影响进行中的世界」；
- 冲突时：并排展示「当前值 / 新值 / 来源」，逐条确认，**禁止静默合并**；
- 模板改动不覆盖运行存档：界面上区分「模板」与「运行存档」两种卡型（UIX-32），另存为副本后才可覆盖。

### 7.6 S6 · 隐私与分享范围

- 任何分享/发布/上云动作前，插入**范围确认卡**：将上传什么、不含什么（私人聊天、礼物史、NPC 私密记忆、真人画像、API Key）打勾列出；
- 密钥输入一律 `type=password` + 遮蔽显示（`sk-••••3f7a`）+ 显隐切换；
- 全局出现「发往哪里」说明（NFR-03）：设置页常驻一句"本次生成将发送至 `<provider>` `<endpoint>`"，不可折叠隐藏；
- 删除类操作必须区分：删账号 / 只删这一局 / 只删作品，三者在视觉与文案上完全不同（UIX-08）。

## 八、关键界面规范

> 完整 71 项映射见附录。此处给出 12 个决定产品气质与正确性的界面。

### 8.1 登录（UIX-01）
- 单列居中卡，宽 400，上 Logo（线性单色）+ 「以邮箱继续」；
- 字段：邮箱、密码（显隐）、登录；下方文字链：注册 / 找回；
- 校验内联、不等提交；登录中按钮变加载态；失败在**表单顶部** InlineAlert 给原因，不清空密码；
- 禁止：社交登录占位按钮、营销插画占半屏。

### 8.2 会话列表（UIX-13）— 默认落地页
- 顶部：当前世界切换器 + 搜索；
- 分组：置顶 / 私聊 / 群聊 / 酒馆；每项 = 头像 + 名称 + 末条摘要（单行截断）+ 时间 + 状态 Chip；
- 行状态：未读（左侧 6px brand 圆点 + 名称加粗）、正在生成（脉冲点）、忙碌（灰点 + 「在忙」）、失败（红点 + 「未完成」）、NPC 主动联系（「TA 找过你」角标）；
- 空态：「还没有会话 → 从名册里挑一个人开始聊」+ 一个行动按钮（**必须能不创作就直接开始**）。

### 8.3 私聊会话（UIX-14）
```
顶部栏：头像 名称 状态 · [世界内时间]   右：更多
消息区：最大宽 720，居中；气泡最大宽 72%
  角色消息：左，白底 + 1px 线，圆角 12
  玩家消息：右，--brand-soft 底，无描边
  系统叙述：居中 13px 灰（移动、时段变化、事件结果）
  不可辨消息：虚线 + 斜体 + 「听不清」角标
输入区：文本域（最高 5 行）+ 表情 + 行动入口 + 发送
行动区（UIX-17）：横向 Chip 组【送礼】【邀请】【承诺】【离开】…（移动收进「+」）
```
- 生成中：气泡内 1px 竖线光标 + 「停止」按钮在输入区上方，**停止后保留已生成文本 + 「已停止」标记**；
- 消息级操作（长按/右键）：编辑、删除、复制、重生成（仅末条）、引用、点名。重生成弹提示「不会重复结算已发生的事件」；
- 顶部状态与角色状态一致，不得显示"在线/离线"这类聊天软件概念（角色没有在线状态，只有忙碌/缺席/在场）。

### 8.4 酒馆会话（UIX-16）+ 俯视小窗（UIX-18）
- 三段：顶部在场条（头像横排 + 谁在说话高亮）、中部消息流、底部输入；
- 小窗（桌面）：右侧栏常驻，宽 280–320，可收起；俯视 2D 线稿风：
  - 圆点 = 人（ diameters 12），姓名 12px；连线 = 正在交流（虚线 = 你在范围内但听不清）；
  - 你的感知范围 = `--brand` 12% 填充 + 虚线圆；
  - 圈外：纯底，不画任何东西（包括暗色人影）；
  - 图例常驻底部：可辨 / 可感知不可辨 / 不在范围；
- 小窗（手机）：折叠卡，展开 ≤40% 屏高；
- 移动（UIX-19）：展开时可点选落点 → 显示「走过去」确认 Chip；收起时用指令「走近 老陈」或行动区「走近某人」。两种入口写同一个移动意图，状态回显一致：`已受理 → 移动中 → 已到达 / 被挡住 / 被日程拒绝`（**UNR-E04 未拍板，UI 先做可切换的两套，不写死**）。

### 8.5 NPC 名片（UIX-25）
- 头图区：大头像 64 + 名称 + 一句话身份 + 状态 Chip（在忙/在场/缺席）；
- 分区（折叠）：身份与外观 / 背景 / 性格与目标 / 说话方式 / 可见动态 / 你们的关系（描述，无数值）；
- 只读与可编辑用同一视觉语言区分：可编辑字段右侧有细微铅笔图标（hover 出现），只读字段无；
- 字段缺失显示「未设定」而不是留白或编造；
- 底部常驻行动：私聊、送礼、加入群聊。

### 8.6 关系视图（UIX-29）
- 桌面默认**列表**为主、图为辅（图更占地方且不易读）；手机只有列表；
- 列表每行：双方头像 → 方向描述 A→B、B→A → 最近变化（可点开看依据）→ 「查看共同经历」；
- 关系图：节点圆形 40，连线粗细 = 熟悉度（**不标注数字**），颜色区分关系类型；图不可用时给完整文本替代（NFR-09）；
- 图例与筛选常驻：只看与我有关的 / 只看 NPC 之间 / 按关系类型。

### 8.7 世界详情（UIX-33）与创建编辑（UIX-34）
- 详情：标题用衬线 `--fs-h2`；七类设定（起源与力量、地理、种族、势力、生物、年表、重要角色）为折叠分区，每区可单独编辑与标记来源；
- 顶部元信息条：题材、版本、派生来源、模板/运行存档标识；
- 创建：桌面分栏（左步骤导航 / 右表单），手机分步（进度条 + 每步一屏）；
- AI 生成内容必须有「生成」角标，且**追加与覆盖是两个不同按钮**，覆盖需二次确认；
- 身份选择（UIX-35）：两个大卡并列——「以旅人进入」/「设定世界内身份」，各自说明差异；可勾选"复制我的资料卡"；明确一句"改这个世界的身份，不会影响其他世界里的你"。

### 8.8 规则与提示词（UIX-37 / UIX-38）
- 列表：名称 / 作用域 Chip（全局 / 单个 NPC / 选定 N 个）/ 启停开关 / 版本 / 最后修改；
- 作用域选择用多选器，选中后 Chip 显示数量与可展开名单；
- 冲突检视（桌面优先）：并排「规则 A（来源）｜规则 B（来源）｜实际生效」+ 一句优先级说明；
- 越权时：**拒绝并明示**——「这条规则试图覆盖安全边界，不会被采用」，红条 + 指向具体行；
- 导入的角色提示词在此处显示「不可读取密钥 / 不可执行本地命令」的静态声明。

### 8.9 进入世界简报（UIX-56）
- 首次进入时居中卡（可关闭，宽 640），三段：
  1. **公开大事**（世界内可公开得知的）
  2. **你能够知道的变化**（严格按五层过滤）
  3. **与你有联系的人**（谁找过你、谁的承诺到期）
- 顶部一行：「你离开了 6 小时 12 分 · 世界按现实时间继续」；
- 禁止出现：你不在场时的私密对话、全知视角的叙述、NPC 的隐藏想法；
- 降级场景（额度耗尽）：卡头 InlineAlert「这期间为规则级推进，非完整生成」。

### 8.10 纪事时间线（UIX-52）与承诺线索（UIX-54）
- 纪事条目：时间（世界内 + 现实）/ 参与者头像组 / 地点 / 一句话结果 / 「后续」链接；可按世界、角色、时间筛选；
- 承诺与线索：未完成置顶，每条带「回到原会话」按钮（深链到具体消息）；已完成折叠在下方；
- 普通记录**不暴露 NPC 隐藏认知**；记忆、调度原因、实际提示词只在「高级检视」（默认关闭，需显式开启）中出现（UIX-57）。

### 8.11 广场与混搭（UIX-58 – UIX-62）
- 浏览：卡片网格，卡 = 封面（纯色/线稿占位，不强制图）+ 类型 + 标签 + 作者 + 版本 + 依赖数；
- 详情：预览区（明确标注"预览不含私人内容"）、依赖清单（缺失项红标）、授权说明、两个按钮【下载整世界】【只下载角色 X】；
- 混搭差异确认（UIX-61）：全屏两栏对照，逐条列出字段冲突 / 引用冲突 / 规则冲突 / 命名冲突 / 授权冲突，每条三选一（保留 A / 保留 B / 都保留并改名），底部「原作不会被修改」声明 + 确认后生成派生世界。

### 8.12 设置 · 模型与 API（UIX-05 / UIX-50）
- Provider 选择 → 密钥输入（遮蔽）→ 测试连接 → 状态 Chip（未配置 / 已配置 / 校验失败）→ 撤销授权（二次确认）；
- 常驻说明：当前生成将发往的地址（不可折叠）；
- 无 Key 的本地路径（Ollama 等）**不能被全局"缺少 Key"横幅拦住**：横幅只对需要 Key 的 Provider 出现；
- 未配置时：提供「使用演示 / 规则级推进」，并明确标注演示内容与真实生成的区别（UIX-04）。

## 九、文案规范

### 9.1 用语词典（UIX-G05）

| 用这个 | 不用这个 | 原因 |
| --- | --- | --- |
| 删除 | 移除、清除、干掉 | 同一动作同一说法 |
| 撤销 | 回退、反悔 | 撤销 = 未提交的操作 |
| 恢复（存档） | 回滚、还原 | 回滚特指历史回退，语义更强 |
| 已确认 | 成功、搞定 | 事务语义 |
| 被拒绝 | 失败、不同意（红） | 拒绝是角色侧，中性 |
| 未完成 | 出错（当指事务未结算） | — |
| 处理中 | 加载中、请稍候 | — |
| 在忙 / 缺席 | 离线、隐身 | 角色没有在线状态 |
| 听不清 | 未知内容 | 用户能懂 |
| 稍后再来 / 去找别人 | （什么都不给） | 忙碌必须给可替代下一步 |

### 9.2 句式规则

1. **主语明确**：说清是"谁"做的——「老陈没有回应」vs「请求失败（ERR-…）」，绝不模糊成"操作未完成"。
2. **给下一步**：每条错误/空态/拒绝后必须有一个可点击的行动。
3. **不拟人化系统**：系统提示不用第一人称，不用表情符号堆砌，不用"哎呀"。
4. **不承诺未发生**：未保存前不写"已保存"；未确认前不写"已送出"。
5. **时间格式**：会话内用相对时间（3 分钟前）；纪事/流水用绝对时间（`2026-10-09 20:14`）并附世界内时间（`暮时 · 第三日`）。
6. **数值**：不显示好感分、置信度百分比以外的内部权重；置信度用「较有把握 / 有些线索 / 只是猜测」三档词 + 来源。
7. **长度**：按钮 ≤ 6 字；错误说明 ≤ 2 行；空态说明 ≤ 1 句。

## 十、无障碍（WCAG 2.1 AA，NFR-09）

| 项 | 要求 |
| --- | --- |
| 对比度 | 正文 ≥ 4.5:1（本规范所有文本 token 均已达标）；大字 ≥ 3:1；图形与状态边界 ≥ 3:1 |
| 焦点可见 | 焦点环 2px `--brand` + 2px 偏移，圆角跟随控件；**不得** `outline: none` |
| 键盘 | 仅键盘可完成：登录、进入会话、发起送礼、确认、保存设置、提交作品。Esc 关闭弹层，焦点回到触发元素 |
| 读屏 | 所有图标按钮有 `aria-label`；状态 Chip 的文字可被朗读（不能只有颜色）；关系图提供文本替代；生成中用 `aria-live="polite"` 播报「正在生成 / 已停止」 |
| 触控 | 可点区域 ≥ 44×44（桌面图标按钮 40 可接受）；相邻可点区 ≥ 8px |
| 动效 | 遵守 `prefers-reduced-motion`；无闪烁（<3 次/秒） |
| 缩放 | 200% 文本缩放不破版；不支持横向滚动（表格除外，允许区域滚动） |
| 表单 | 错误用 `aria-describedby` 关联说明；必填用 `required` + 文字「必填」而非仅星号 |
| 键盘软键盘 | 移动端输入区不被遮挡，主行动按钮在键盘上方可见 |

### 12.2 Design QA 检查表（每个界面过一遍，全 ✅ 才交付）

**正确性**
- [ ] 界面上没有出现感知范围外、受众外、未授权的信息（连灰色占位都没有）
- [ ] 系统状态与角色状态在颜色、位置、文案主语上三重区分
- [ ] 事务五态齐全，且"被拒绝"不是红色
- [ ] 未确认前没有任何"已完成"的表达
- [ ] 关系界面没有任何数值、进度条、星级

**完整性**
- [ ] 空 / 加载 / 错误 / 边界 四态稿齐全
- [ ] 每次操作都有 ≤1s 的可感知反馈
- [ ] 危险操作有二次确认，重要操作可撤销或可恢复
- [ ] 同一任务手机和桌面都能完成

**一致性**
- [ ] 颜色、字号、间距全部来自本文档 token，无硬编码值
- [ ] 同一操作的名称与结果与其它界面一致
- [ ] 图标语义唯一，无两个图标表达同一件事

**可用性**
- [ ] 仅键盘可完成核心任务，焦点环可见
- [ ] 触控区 ≥44，对比度 ≥4.5:1
- [ ] 动效遵守 reduced-motion

**克制与质感（v1.1 新增）**
- [ ] 投影全部来自 `--sh-sm/md/lg`，暖灰低透明，无生硬黑投影
- [ ] 高饱和彩色只出现在主行动按钮与关键链接，一屏 ≤1 处
- [ ] 每个卡片只有一个视觉焦点；次要信息用 muted 色，不与核心信息同级同重
- [ ] 关联内容间距 ≤8px（就近原则），无用"分隔线补结构"的情况
- [ ] 头像带内描边与纸感渐变底，与背景融合而非悬浮
- [ ] 导航与分区无硬边框；选中态用白卡/底色微差表达
- [ ] 渐变只允许 `--grad-soft` 一处；图像上文字必有蒙版
- [ ] 滚动触发动画只进不出、只触发一次，且有 1.5s 显示兜底

**克制（原有）**
- [ ] 没有为了好看而增加的装饰（渐变、插画、多余动效）
- [ ] 没有为了填满版面而生成的占位内容
